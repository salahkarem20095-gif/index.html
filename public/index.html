⚠️ Vulnerability Testing Exercises

Educational Purpose Only: This application contains deliberate security vulnerabilities for educational purposes. Only test on your local machine. Never test on websites without explicit permission.

Available Exercises

1. SQL Injection

Learn how SQL injection works and how to exploit it.

POST http://localhost:3000/login

Try these payloads in the username field:

' OR '1'='1
' OR 1=1 --
Go to Login Page →

2. Cross-Site Scripting (XSS)

Learn how XSS vulnerabilities allow script injection.

GET http://localhost:3000/xss?name=<script>alert('XSS')</script>

Try injecting JavaScript code through the name parameter.

Go to XSS Page →

3. Insecure Direct Object References (IDOR)

Learn how to access unauthorized resources by manipulating IDs.

GET http://localhost:3000/profile?id=1

Try changing the id parameter to access other users' profiles.

Go to Profile Page →

4. Broken Access Control

Learn how improper access controls can be bypassed.

GET http://localhost:3000/admin?role=admin

Try manipulating the role parameter to gain admin access.

Go to Admin Page →

5. Path Traversal

Learn how to access files outside the intended directory.

GET http://localhost:3000/file?file=../../etc/passwd

Try using directory traversal sequences to access sensitive files.

Go to File Page →

6. Information Disclosure

Learn how sensitive information can be exposed.

GET http://localhost:3000/debug

This endpoint exposes sensitive system information.

Go to Debug Page →

7. Insecure API Endpoints

Learn about API security vulnerabilities.

GET http://localhost:3000/api/users/1

This API endpoint exposes user data without authentication.

Go to API Page →

Tools You Can Use

  • Browser Developer Tools: F12 to inspect requests and modify parameters
  • curl: Command-line tool for making HTTP requests
  • Burp Suite: Web application security testing tool
  • OWASP ZAP: Free web application security scanner

Getting Started

  1. Start the server: npm start
  2. Open browser to http://localhost:3000
  3. Try each exercise and see if you can exploit the vulnerability
  4. Read the detailed exercise guides in the exercises/ directory
